# Projeto Modelo Node + React

Estrutura de estudo full-stack com um backend Node.js/Express conectado ao MySQL por Sequelize e uma pasta separada para o front-end React.

## Stack
- Node.js e Express
- MySQL e Sequelize
- React

## Como executar
O backend está em `back-end` e o front-end em `front-end`. Os arquivos `package.json` atuais não definem scripts de inicialização; instale as dependências em cada módulo e execute os pontos de entrada configurados no código.
