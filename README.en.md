# Node + React Starter Project

A full-stack study structure with a Node.js/Express backend connected to MySQL through Sequelize and a separate React front-end folder.

## Stack
- Node.js and Express
- MySQL and Sequelize
- React

## Run
The backend is under `back-end` and the front end under `front-end`. The current `package.json` files do not define start scripts; install dependencies in each module and run the entry points configured in the source code.
